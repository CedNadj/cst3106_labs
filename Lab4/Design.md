# Cedric Nadjibé's Design System Documentation

## Introduction

This document outlines the design system used for my personal portfolio project.
It defines the visual language - colors, typography, and layout principles - to ensure consistency across all web pages and components.

---

## Color Palette

| Color Role  | Hex Value  | Example Usage  |
|-------------|------------|----------------|
| **Primary** | `#4A90E2` | Buttons, active links, icons |
| **Secondary** | `#F5A623` | Highlights, hover states |
| **Background** | `#F8FAFC` | Page background |
| **Surface / Card** | `#FFFFFF` | Containers and cards |
| **Text (Primary)** | `#1E293B` | Headings and main body |
| **Text (Muted)** | `#64748B` | Secondary text |
| **Success** | `#10B981` | Notifications or status |
| **Error** | `#EF4444` | Error messages or invalid states |

---

**Rationale:**  
The palette combines calm blues with warm orange accents for balance and energy. The neutral background ensures good readability and accessibility.

---

## Typography

- **Heading font:** *Poppins*, sans-serif  
- **Body font:** *Inter*, sans-serif  
- **Accent font:** *Playfair Display*, serif  

| Text Element  | Font Size  | Weight  | Use  |
|---------------|------------|---------|------|
| H1 | 2.5rem | 700 | Main titles |
| H2 | 2rem | 600 | Section headings |
| H3 | 1.5rem | 500 | Subheadings |
| Paragraph | 1rem | 400 | Body text |
| Caption | 0.875rem | 300 | Metadata, small notes |

---

## Layout Structure

### Header
- Fixed top navigation bar with a white background and drop shadow.  
- Left-aligned logo with right-aligned navigation links.  
- Links change color to blue (`#4A90E2`) on hover.

### Hero Section
- Prominent introduction with name and tagline.  
- Includes a “View Projects” button in primary blue.  
- Background gradient from `#F8FAFC` to `#E2E8F0`.

### Projects Section
- Grid layout displaying project cards (3 per row on desktop, 1 per row on mobile).  
- Each card shows an image, title, and short description.  
- Hover effect: slight lift and shadow increase.

### Footer
- Darker background (`#1E293B`) with white text.  
- Contains social media icons and copyright.
